## 6. Core Web Vitals & Technical Performance

Web gaming SEO requires instant responsiveness. Players bounce immediately if loading exceeds 3 seconds.

- **LCP (Largest Contentful Paint)**: < 1.2s. Preconnected fonts, zero external audio asset requests (audio is synthesized client-side via oscillators), and minimal CSS overhead.
- **FID / INP (Interaction to Next Paint)**: < 50ms. Matter.js collision detection runs on a dedicated fixed-timestep loop with lightweight 2-substep calculations, ensuring 60FPS fluid touch drag across low-end mobile devices.
- **CLS (Cumulative Layout Shift)**: 0.00. The game canvas container has explicit aspect-ratio constraints and reserved dimensions. Ad slots (`min-height: 90px`) reserve layout space before Google AdSense scripts execute, eliminating layout jumps.

## 9. Search Console, Bing & Analytics Setup Guide

### 9.1 Google Search Console Verification
1. Navigate to [Google Search Console](https://search.google.com/search-console).
2. Select **URL prefix** and enter: `https://stardustmerge.vercel.app/`
3. Choose the **HTML tag** verification method.
4. Copy the verification token (e.g. `google-site-verification=...`) and place it inside the `<meta name="google-site-verification">` tag in `index.html`.
5. Once verified, submit the sitemap URL: `https://stardustmerge.vercel.app/sitemap.xml`.
6. Inspect the homepage URL to request initial indexing.

### 9.2 Bing Webmaster Tools
1. Navigate to [Bing Webmaster Tools](https://www.bing.com/webmasters).
2. Sign in and choose **Import from Google Search Console** for instant automatic verification, or use the meta tag method with `<meta name="msvalidate.01">`.
3. Submit `https://stardustmerge.vercel.app/sitemap.xml`.

### 9.3 Google Analytics 4 (GA4) Event Taxonomy
We have implemented a privacy-conscious, non-blocking telemetry hook in `index.html`. To track key gameplay metrics, insert your Measurement ID into `gtag('config', 'G-XXXXXXXXXX')`:

- `game_start`: Fired upon the first orb drop of any session.
- `merge_tier`: Fired when high-tier bodies form (`tier >= 8`).
- `supernova_triggered`: Fired when two Black Holes merge.
- `mode_switch`: Fired when switching between Endless, Daily, and Zen.
- `perk_selected`: Fired when drafting a Cosmic Perk milestone.
