🚀 What Is Stardust Merge?

Stardust Merge is an original, free-to-play web game blending tactile 2D physics puzzles with roguelite progression and cosmic aesthetic design. Built entirely with standard open web standards (HTML5 Canvas, Matter.js, and the Web Audio API), it runs instantly on desktop and mobile browsers with zero downloads, zero account requirements, and instant restart times.

1. The Vision Behind the Game

Too many modern mobile and browser games are burdened by heavy multi-megabyte downloads, mandatory account registrations, invasive notification permissions, and pay-to-win microtransactions.

Stardust Merge was built as an antidote: a return to the pure joy of classic web arcade gaming. We set out to create a game that opens in under one second, feels soothing and cozy to play, yet offers immense strategic depth for high-score puzzle enthusiasts.

2. Technical Architecture & Zero-Bloat Philosophy

Every technical choice in Stardust Merge prioritizes speed, battery efficiency, and player privacy:

  • Single-File Static Core: The entire game engine, audio synthesizer, particle system, and physics simulation are bundled into a lean, self-contained client.
  • Real-Time Web Audio API Synthesis: Rather than forcing players to download megabytes of audio files, all sound effects (merges, chimes, celestial hums, supernova detonations) are generated mathematically on the fly via browser audio oscillators.
  • Matter.js 2D Rigid Body Physics: We utilize a multi-substep physics integration cycle to ensure collision stability across 60Hz, 120Hz, and 144Hz high-refresh displays without tunneling.
  • Client-Side LocalStorage: All achievements, cosmetic skin unlocks, high scores, and sound settings remain completely on your local device. We never sell or transmit your personal data.

3. Meet the Studio

Stardust Merge is developed and maintained by Stardust Merge Arcade Studio, led by indie software engineer Prit Patel. Our passion is crafting timeless, accessible browser games that respect player autonomy and device resources.
